# Review logs

One plain-language log per implementation plan (`NN-<slug>.md`, from `docs/implementation/templates/REVIEW_LOG_TEMPLATE.md`), written for a reviewer who was not in the room and may not be an expert in the topic. Each log says what was built, why, how to check it, what changed from the plan, what is risky, and what the next plan needs to know. If something is unfinished or shaky it says so plainly. A change to the API contract is flagged at the very top under "CONTRACT CHANGE — teammates must know".
